# ELNA — Entertainment Live Network Arena

ELNA is an offline quiz show console for Windows. Run a live quiz from one
operator screen, with separate Contestant and Broadcaster windows and an NDI
source for each, ready for vision mixers and streaming software such as OBS.

## Download

Download the latest Windows installer (`ELNA-NDI-Setup-<version>.exe`) from
this repository's [Releases](../../releases) page, run it, and open ELNA from
the Start menu. The installer includes the NDI Runtime.

Windows 10 or 11 (64-bit) is required. Windows may show a SmartScreen notice
for a newly downloaded installer; choose **More info**, then **Run anyway**.

## First use

ELNA includes a free trial: every feature, for 20 minutes of live use a day,
on up to 30 different days per computer. While on the trial, the Contestant
and Broadcaster pictures, and so the NDI feed, carry an "ELNA Trial"
watermark. Building and editing quizzes is never limited.

To license ELNA, open the **License** page, copy the **Machine ID** and send
it to contact@arsi.in. You will receive a license file for that computer;
choose **Install license file** on the same page to activate it.

## Updates

ELNA checks this repository for new versions when it starts and offers to
install them. Each release lists what changed.

Most updates are optional: choose **Later** to keep working and install at
another time. An important fix may be marked **required**; ELNA then asks you
to install it before you can continue. The check needs an internet
connection, so a show running offline is never interrupted.

## Your data

Quizzes, teams and scores stay on the computer where ELNA is installed.
ELNA does not need an internet connection to run a show.
